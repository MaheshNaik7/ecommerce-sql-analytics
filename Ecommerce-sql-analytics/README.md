# E-commerce Sales Analytics

## Overview
SQL project for analyzing e-commerce sales data using MySQL.

## Database Schema
- **customers** — Customer information
- **products** — Product details
- **orders** — Order records
- **order_items** — Order line items

## Analyses Included
1. Total revenue generated
2. Revenue by category
3. Top 3 best selling products
4. Monthly revenue trend
5. Top customers by spending
6. Cities with most customers

## How to Use
1. Run `database_setup.sql` to create tables
2. Run `sample_data.sql` to insert sample data
3. Run queries from `analytics_queries.sql`

## Technologies
- MySQL
- SQL
