OVERVIEW

SQL project for analyzing e-commerce sales data using MySQL.

DATABASE SCHEMA
CUSTOMERS — Customer information
PRODUCTS — Product details
ORDERS — Order records
ORDER_ITEMS — Order line items

ANALYSES INCLUDED
Total revenue generated
Revenue by category
Top 3 best selling products
Monthly revenue trend
Top customers by spending
Cities with most customers

HOW TO USE
Run database_setup.sql to create tables
Run sample_data.sql to insert sample data
Run queries from analytics_queries.sql

TECHNOLOGIES
MySQL
SQL
